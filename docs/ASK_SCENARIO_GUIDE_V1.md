# 问事场景引导与问题模板库

## 目标

为不知道如何组织问题的用户提供八类常见场景和参考问法；自由输入始终是问事的主入口。

## 交互

用户可直接在原有输入框写下问题，也可先选择感情、工作、财运、合作、人际、学业、出行或选择。点击模板只会回填输入框，用户仍可修改并主动点击原有起卦按钮。输入框已有内容时，系统会先请求确认，不会静默覆盖。

## 数据与降级

场景和模板由 `AskQuestionTemplateLibrary` 提供，包含排序、启用状态与基础完整性校验。配置为空或校验不通过时，引导组件隐藏，原有自由输入与起卦流程保持可用。

## 安全边界

模板使用“是否适合”“是否值得”“需要注意什么”等参考性措辞，不提供医疗、法律、投资、赌博、生死或确定性预测模板。本功能不新增 AI 调用，不记录用户输入全文，也不自动选择术数方法。

## 未修改能力

金钱卦、小六壬、梅花易数、高岛易断、每日一卦的算法、featureId、起卦结构、历史、resultSnapshot、分享、路由、钱包与支付均未修改。

## 测试范围

验证场景数据完整性、模板回填、已有文字保护、配置异常降级，以及四个既有问事入口的接入。Web 与 Android 均使用同一 Flutter 组件。
